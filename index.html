04 / THE DETAILS

READ THE MANUAL.

The things worth knowing before you build.

01 Is this another coding agent?+

Olivium Harness builds the instructions, workflows, and checks around your agent. It exports native packages for Codex CLI, Claude Code, and OpenCode, so your team’s context can travel into the tools you use.

02 What can I use as context?+

Selected Markdown or text documents; GitHub metadata, issues, pull-request descriptions and reviews; GitHub Projects; Jira Cloud issues; Slack threads; and Confluence Cloud pages. GitHub imports do not currently ingest repository source files. Current cross-source analysis uses two to four selected documents and one saved goal.

03 Who approves the instructions?+

You do. Recommendations include supporting evidence for review. You can edit, reject, and resolve conflicts before approving an exact revision. The package plan requires a separate approval before the harness is built.

04 Does local-first mean no cloud AI?+

Cloud AI is optional. If you choose a cloud model provider, selected context can leave your machine with your consent. Provider access and spending are controlled explicitly.

05 What is the project’s current status?+

Olivium Harness is an open-source tool under Apache 2.0, in active development. The landing-page implementation is proprietary and its source repository is private. The application is a separate project with its own licensing and currently requires repository permission. A public product release is not yet available. The animations on this page are illustrative. Export support is separate from validation of an agent’s live runtime.
